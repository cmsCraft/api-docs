# api-docs

A Nextra site that publishes the documentation of the cms-craft public GraphQL API. It owns no data: it renders
hand-written guides plus a reference generated from the public schema. This file is the glossary of this repo's own
vocabulary.

## Terms this repo owns

| Term | Means here | Source |
|---|---|---|
| Public schema | The SDL of the public GraphQL endpoint, copied from main-craft's published public schema when the API changes | `schema/schema.public.gql` |
| Schema download | The public schema served as a static file at `/schema.graphql`, for code generators | `scripts/gen-reference.mjs` |
| Reference page | One generated page under `content/reference/` for a type or operation of the public schema | `graphql.config.js` |
| Example check | The validation of every `graphql` block in the hand-written pages against the public schema | `scripts/check-examples.mjs` |
| Nextra route | A URL of this site, resolved from one `content/**/*.mdx` / `.md` file by the catch-all page | `app/[[...mdxPath]]/page.jsx` |

## Language

### Public schema

The one schema source of the site. It is copied from main-craft's public schema; main-craft CI opens a
`bot/schema-sync` PR when it changes. Both the **Schema download** and the **Reference pages** are built from it.
_Avoid_: editing it by hand, or reading the schema from anywhere else (introspection is disabled in production).

### Reference page

Generated by `pnpm gen:reference` (`@graphql-markdown/cli`) into `content/reference/` (gitignored). The section's
landing page (`/reference`) is written to `.schema/index.md` and copied in by the generator.
_Avoid_: hand-editing anything in `content/reference/`; it is rebuilt on every `dev` and `build`.

### Example check

Runs in `prebuild`. A `graphql` example that does not parse or does not validate fails the build, so the guides can
never show a field or argument the API does not have.

### Nextra route

Every page maps to one file under `content/`. Sidebar labels and ordering come from the sibling `_meta.js` files.
_Avoid_: expecting a route file per page under `app/`; there is one catch-all route for the whole site.

## Clashes

| Term | Here (api-docs) | In the API |
|---|---|---|
| Content | An MDX file under `content/` | A page or post of a cms-craft project (the `Content` type) |
| Schema | The public SDL this site documents | The API's full GraphQL schema, of which the public schema is a subset |
| Token | Not a concept of this repo; the docs describe two | The project **API token** (`project-auth` header) and the **revalidation secret** (`x-revalidate-token`) |
