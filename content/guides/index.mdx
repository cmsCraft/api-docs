# Guides

Task-by-task guides to the public API. Every example needs the `project-auth` header, see
[Authentication](/auth). For every operation and field, see the [API Reference](/reference).

- [Querying content](/guides/querying-content): read the project's published pages, posts and other records.
- [Pagination](/guides/pagination): page through list queries with `PageOptionsInput`.
- [Localization](/guides/localization): find the project's languages and ask for content in one of them.
- [Filtering products](/guides/filtering): narrow `publicProducts` with the `where` argument.
- [Form mutations](/guides/mutations): submit the public forms (contact, newsletter, orders, bookings…) from your
  server.
- [E-shop (beta)](/guides/shop): read the shop settings and create orders.
- [Cache revalidation](/guides/revalidation): handle the request cms-craft sends when an editor saves something.
- [Code examples](/guides/code-examples): one query in several languages, called from a server.
