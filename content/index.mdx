# cms-craft Public API

cms-craft is a multi-tenant headless CMS. Its **public GraphQL API** lets you build your own frontend on top of one
cms-craft project: you read the project's published content (pages, blog posts, products, categories, pets, schedules
and more) and submit a few public forms (contact requests, newsletter sign-ups, orders, bookings, event registrations,
adoption requests).

It is meant for freelancers and small agencies who build a client's site with the framework of their choice (Next.js,
Astro, Nuxt, SvelteKit, a static site generator…) while the client edits the content in the cms-craft admin panel.

- **Endpoint:** `https://main-craft.cms-craft.com/graphql/public`
- **Protocol:** GraphQL over HTTP: `POST` with a JSON body (`GET` also works for queries)
- **Auth:** your project's API token in the `project-auth` header, see [Authentication](/auth)
- **Where to call it from:** your server (SSR, route handlers, build scripts), see [why](/auth#call-the-api-from-your-server)
- **Schema:** [download `schema.graphql`](https://docs.cms-craft.com/schema.graphql) or browse the [API Reference](/reference)

**Start here:** the [Quickstart](/getting-started) takes you from a token to a working Next.js or Astro page, including
the cache refresh endpoint cms-craft calls when the content changes.

## Getting access

Request access yourself: sign up at the cms-craft admin, create a project, and as its owner send **Request API access**
under **Settings → Integrations**. When staff approve it (you get an e-mail), the same page shows the endpoint, your
usage and the API token ([Authentication](/auth#getting-the-token)). Questions, or a site cms-craft hosts:
support@cms-craft.com.
